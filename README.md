# Uzaylı Dil Çevirici

## Proje Özeti

Bu proje, insanlığın en büyük sorunlarından birini çözmek için tasarlanmıştır: **Uzaylılarla iletişim**.

Yıllar süren (aslında 5 dakikalık) araştırmalarımız sonucunda, uzaylıların dilinin aslında rastgele seslerden ve Türkçe kelimelerin karışımından oluştuğu bilimsel olarak kanıtlanmıştır (kanıtlanmamıştır, ama kulağa hoş geliyor).

Bu araç, herhangi bir Türkçe metni gerçek zamanlı olarak "uzaylı diline" çevirir. Çeviriler %100 doğrudur, %0 yanlış olabilir, %50 şansa bağlıdır.

## Özellikler

- **Gerçek zamanlı çeviri**: Yaz, çevir, şaşır.
- **Bilimsel kelime havuzu**: Blorg, zorp, quib gibi kanıtlanmış uzaylı kelimeleri içerir.
- **Türkçe entegrasyonu**: Bazen orijinal saçma Türkçe cümleler de çıkar, çünkü uzaylılar da Türkçe öğreniyor.
- **Onay sistemi**: Her çeviri sonunda uzaylı onayı gelir (Evet/Hayır/Belki/Kedi Onayladı).
- **Hata toleransı**: Hata olursa uzaylılar anlamaz, siz de anlamayın.
- **Gizli özellikler**: Kodun içinde gizli mesajlar vardır. Arayan bulur, bulmayan uzaylı olur.

## Kurulum

```bash
git clone https://github.com/Tentivory/uzayli-dil-cevirici.git
cd uzayli-dil-cevirici
python3 uzayli_cevirici.py
```

Python 3 yeterlidir. Başka bir bağımlılık yoktur, çünkü uzaylılar pip kullanmaz.

## Kullanım

Programı çalıştırın, metin girin, çeviriyi okuyun, gülün veya ağlayın.

Örnek:
```
Çevrilecek metin: merhaba dünya
Çeviri: blorg zorp merhaba uzaylı dostum (Uzaylı Onayı: Belki)
```
